## Complexidade do Algoritmo

O programa percorre o array algumas vezes. Mesmo que tivéssemos 100, 1.000 ou 10.000 temperaturas, a quantidade de operações aumentaria proporcionalmente ao tamanho do array.

Por isso, a complexidade do algoritmo é **O(n)**, ou seja, uma **complexidade linear**.

Isso significa que, conforme o número de temperaturas aumenta, a quantidade de operações também aumenta de forma proporcional.

Por exemplo:

- 10 temperaturas → aproximadamente 50 posições percorridas;
- 100 temperaturas → aproximadamente 500 posições percorridas;
- 1.000 temperaturas → aproximadamente 5.000 posições percorridas.

Portanto, o algoritmo apresenta crescimento linear, representado por **O(n)**.
